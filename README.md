🎬 Netflix SQL Data Analysis Project
📌 Project Overview

This project focuses on analyzing the Netflix dataset using SQL in MySQL Workbench. The dataset contains information about movies and TV shows available on Netflix, including title, director, country, release year, rating, duration, and category details.

The main objective was to perform data analysis using SQL queries and gain practical experience in working with structured databases.

🎯 Objective

To use SQL queries for extracting meaningful insights from the Netflix dataset and demonstrate core SQL concepts used in data analysis.
